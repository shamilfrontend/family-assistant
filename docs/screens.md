# Экраны

Маршруты Vue Router. Взрослый и ребёнок — одни и те же path, разный набор действий. Отдельный «крупный» детский UI — фаза 2. Покупки и чат должны быть удобны с телефона.

RBAC совпадает с [README.md](../README.md) и [api.md](api.md). Клиент прячет кнопки; сервер — источник запрета.

## Навигация

**Гость:** `/` — лендинг с возможностями продукта; `/register`, `/login`, `/invite/:token` — как раньше. Защищённые маршруты без сессии → `/login`.

**Вход выполнен, нет семьи** — в продукте не бывает: семья создаётся вместе с регистрацией, приглашение сразу клеит к семье.

Мобильное нижнее меню:

| Взрослый | Ребёнок |
| --- | --- |
| Сегодня, Календарь, Покупки, Чат, Ещё | Сегодня, Календарь, Покупки, Чат, Ещё |

«Ещё» (взрослый): дела, документы, здоровье, бюджет, семья.  
«Ещё» (ребёнок): мои дела, мои документы, моё здоровье, профиль (чтение). Настройки семьи и бюджет ребёнку не показываются; прямой заход на `/family`, `/family/members`, `/family/invites`, `/budget` → редирект на `/`.

Desktop: боковое меню с теми же пунктами.

Меню растёт по подфазам: **1.1** — «Сегодня»-заглушка, «Ещё» → семья / профиль; **1.2** — Календарь; **1.3** — Покупки, Чат; **1.4** — дела и документы в «Ещё»; **1.5** — здоровье в «Ещё». Таблица ниже — полный MVP.

## Маршруты

| Path | Кто | Подфаза | Зачем |
| --- | --- | --- | --- |
| `/` | гость | 1.1 | Лендинг: возможности продукта, CTA «Создать семью» и «Войти». Вошедший на `/` видит экран «Сегодня». |
| `/register` | гость | 1.1 | Email, пароль, имя, дата рождения, чекбокс 18+, пояс семьи. Создаёт семью и карточку взрослого. |
| `/login` | гость | 1.1 | Email + пароль, cookie-сессия. |
| `/invite/:token` | гость | 1.1 | Превью роли; принятие: email, пароль; для новой карточки — имя и дата рождения; для взрослого — 18+. Истёкший/отозванный токен — сообщение без формы. |
| `/` | оба | 1.2 | Сегодня + «скоро»: события с флагом (сегодня … +7 дней). В 1.1 — заглушка без календаря. С 1.4 — дела на сегодня и документы «скоро истекает» (30 дней). Для гостя `/` — лендинг (см. выше). |
| `/calendar` | оба | 1.2 | Взрослый: виды день / рабочая неделя / неделя (шкала часов) и месяц; фильтр по члену. На узкой ширине месяц — список, не сетка. Ребёнок — свои ближайшие (участник, список на 30 дней), без фильтра, без видов и без создания. Прямая карточка события — если участник, даже вне окна. |
| `/calendar/events/new` | взрослый | 1.2 | Создание события. Тип, дата/весь день, повтор, участники (минимум 1), флаг напоминания. |
| `/calendar/events/:id` | оба | 1.2 | Карточка вхождения (`occurrenceStart` в query). Ребёнок — чтение, если участник. Взрослый — правка «это / вся серия», удаление серии. `HEALTH_APPOINTMENT` (с 1.5) — только просмотр, ссылка в здоровье. Тип `DOCTOR` подписан: «событие, не мед. карта». |
| `/purchases` | оба | 1.3 | Общий список. Быстрое добавление — одно поле названия (категория `OTHER`). Фильтр скрыть купленное. Ребёнок: добавить, галка «куплено» на любую позицию, править своё до покупки; снять «куплено» нельзя. Взрослый: удаление, снять «куплено», очистка купленного. |
| `/tasks` | оба | 1.4 | Взрослый — все дела семьи, создание, удаление, reopen. Ребёнок — свои, отметка «сделано», без создания. |
| `/tasks/:id` | оба | 1.4 | Карточка дела. Ребёнок — только своё. |
| `/documents` | оба | 1.4 | Список, номер замаскирован. Ребёнок — только свои. Индикатор «скоро истекает». |
| `/documents/new` | взрослый | 1.4 | Создание карточки. |
| `/documents/:id` | оба | 1.4 | Взрослый видит полный номер. Ребёнок — своё, номер с маской. |
| `/health` | оба | 1.5 | Взрослый — список членов → здоровье. Ребёнок → редирект на `/health/:свойMemberId`. |
| `/health/:memberId` | оба | 1.5 | Врачи, прививки, осмотры, приёмы. Аллергии — с профиля, не редактируются здесь. Ребёнок — только своё, чтение. Приём ведёт в событие календаря (read-only). |
| `/budget` | взрослый | 2 | Журнал расходов за месяц, сводки по категориям и «кто сколько», правка категорий. Ребёнок — редирект на `/`. |
| `/profile` | оба | 1.1 | Своя карточка. Взрослый правит поля. Оба могут удалить свой вход (`DELETE /auth/account`); последний взрослый — нет. После удаления входа email свободен, повторная регистрация — новая семья. Ребёнок поля не меняет. |
| `/family` | взрослый | 1.1 | Пояс, удаление семьи (превью списка того, что сотрётся + подтверждение). Смена пояса не пересчитывает уже сохранённые события. |
| `/family/members` | взрослый | 1.1 | Карточки: создать без входа, править профиль, роль (не последнего взрослого). |
| `/family/members/:id` | взрослый | 1.1 | Любая карточка. Удаление карточки целиком (не последнего взрослого) удаляет и аккаунт, если он был. |
| `/family/invites` | взрослый | 1.1 | Выдать ссылку/код (роль + карточка или новая), отозвать до использования. Токен показывается один раз. |
| `/chat` | оба | 1.3 | Свой чат. Сообщения, кнопки применить/отклонить у pending-черновика. Нет записи текстом «да». Ребёнок не видит кнопок apply на событие/дело/расход. |
| `/chats/:memberId` | взрослый | 1.3 | Чат ребёнка семьи, только чтение. Писать и жать черновики нельзя. Vue-параметр — memberId; HTTP — `GET /chats/:chatId`. `chatId` клиент берёт из `GET /chats` (`{ chatId, memberId, name }`). |

Несуществующий id — экран 404. Чужой ресурс (чат взрослого, чужой документ ребёнку) — не «пустая карточка», а отказ (клиент после 403).

## Состояния экранов

- **Пустые:** календарь без событий на выбранный период; пустой список покупок; у ребёнка нет дел — короткий текст, без кнопок, которых нет по роли.
- **Ошибки:** сессия истекла → `/login`; LLM недоступна в чате — шаблон «ассистент сейчас не отвечает», история и модули работают.
- **Приглашение:** 48 ч истекли / отозвано / уже использовано — отдельное сообщение, не форма пароля.

## Адаптив

Приоритет телефона: `/purchases` (быстрое добавление по названию, категория не спрашивается) и `/chat` (лента + поле ввода над клавиатурой). Календарь на узкой ширине: месяц — список, не сетка; день и недели — шкала часов (неделя со скроллом колонок). Формы событий и документов — одна колонка.

Нижняя навигация не перекрывает кнопку «добавить» на покупках: плюс на поле ввода, не FAB под таббаром. В режиме «на экран Домой» меню учитывает safe area.
